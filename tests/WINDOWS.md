# Windows 验证记录

验证日期：2026-10-22。环境：Windows 11 x64、Node 22.22.2、Windows Edge 及应用内浏览器。

运行自动检查：`npm ci`、`npm run build`、`npm test`。

自动检查覆盖：中文及空格路径导入、换格式后清理旧文件、阅读记录保存与重启、PDF 字节范围、静态资源缓存、错误网址、分段传输的中文、EPUB 元数据、Windows 文件占用时不破坏记录、ZIP/7z 下载解压、任务排队与取消、缺少 zlib、登录状态、分段 UTF-8 输出、下载和停止子进程。

页面实测：从文件选择器导入 EPUB / GBK TXT / PDF，取书与阅读、翻页、书签、字号、楷体、单页、拖选正文、Ctrl+Enter 保存中文批注、刷新恢复阅读位置和批注、文件夹定位、默认阅读器打开。PDF 在 Windows Edge 中实际显示，检查缩放、查找、两页切换及恢复位置。测试文件只含本项目生成的文字。

启动入口在包含中文、空格及 `&` 的项目副本中完成安装、构建和启动。原来 npm 生成的 Windows 命令包装器在 `&` 路径下失败，现已直接调用对应 Node 程序。

在线书源边界：真实宝库索引和关键词搜索已通过；城通下载流程使用本地替身服务验证（包括真实 Windows 解压工具），未把它当作真实网盘完整下载成功。此电脑未安装并登录 zlib，真实账号搜索下载未验证；相关程序交互用替身验证。登录和第三方网盘的可用性仍取决于账号与站点。

`fixtures/books.7z` 是由 `fixtures.mjs` 生成的测试 EPUB 打包而成，不含用户藏书。
