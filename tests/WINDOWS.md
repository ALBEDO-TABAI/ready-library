运行自动检查：`npm ci`、`npm run build`、`npm test`。

自动检查覆盖：中文及空格路径导入、换格式后清理旧文件、阅读记录保存与重启、PDF 字节范围、静态资源缓存、错误网址、分段传输的中文、EPUB 元数据、Windows 文件占用时不破坏记录、ZIP/7z 下载解压、任务排队与取消、缺少 zlib、登录状态、分段 UTF-8 输出、下载和停止子进程。

启动入口在包含中文、空格及 `&` 的项目副本中完成安装、构建和启动。原来 npm 生成的 Windows 命令包装器在 `&` 路径下失败，现已直接调用对应 Node 程序。
